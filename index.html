About this app

Frame Checklist reads FRAMECAD work orders from Smartsheet (via your Cloudflare proxy), auto-fetches the detailer report and production drawings attached to each job, and lets you check off frames as they're completed. Saving progress uploads a marked-up copy of the detailer report back to the job's row as a new version of the "IN PROGRESS" file.

Known limitations

• Report/drawing matching is by filename pattern — if it guesses wrong, use the "Pick files" option that appears on the job screen.

• Uploads made by this app all show as authored by whichever Smartsheet account the proxy's token belongs to, not the tablet's user.

• Files over 30MB can't be uploaded via the API (Smartsheet's limit).
